# 版本发布 / Releases

本目录存放 DevBox 的**可分发产物**，文件名带版本号，便于下载与后续升级管理。

## 下载与使用

| 类型 | 文件 | 说明 |
|------|------|------|
| 安装包 | `DevBox-Setup-<版本>.exe` | NSIS 安装程序，双击安装，可选安装目录，创建快捷方式与卸载入口 |
| 免安装版 | `DevBox-<版本>.zip` | 解压后**双击 `DevBox.exe` 直接运行**（绿色便携版） |

> 两者均已 Authenticode 签名（发布者 CN=子柒）。首次运行会请求管理员权限（服务/PATH 操作所需）。

## 版本管理约定

- 产物文件名统一为 `DevBox-Setup-<semver>.exe` 与 `DevBox-<semver>.zip`。
- 每次升级：在下方追加版本条目，并把新版本产物放入本目录（保留历史版本，方便回退）。
- 版本号同时体现在：应用「关于」对话框、安装向导欢迎页、`installer/DevBox.nsi` 的 `VIProductVersion`。

## v1.0.0 (2026-10-13)

首个发布版本。

- 多版本环境管理与切换：Java / Node.js / Python / PHP / Maven / MySQL / Redis（shim 透明代理）。
- 国内镜像优先下载 + 断点续传 + 压缩包双重校验。
- MySQL 服务化：多实例、初始化、安装/启停/卸载服务、修改/重置 root 密码、创建用户、查看并复制临时密码。
- Redis 服务化：多实例、安装/启停/卸载服务、内存上限(maxmemory)、访问密码(requirepass)。
- 版本卸载与残留清理：服务 / 进程 / 目录 / 实例配置 / 缓存 / 激活标记 / 失效环境变量(*_HOME) / 空工具目录。
- 运行时 UAC 管理员提权；数据统一存放于 `D:\环境管理\data`，不占用 C 盘。
- 中文图形界面，浅色/深色主题，密码可见切换，「关于」展示版本与 MIT 许可。
